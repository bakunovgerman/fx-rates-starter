# Тестовое задание: Android-разработчик (работа с ИИ)

Мы пишем код вместе с ИИ-агентами и хотим увидеть, как это делаете вы. Инструменты любые:
Claude Code, Cursor, Codex, Gemini CLI, Copilot, Junie. Бесплатных вариантов тоже достаточно:
Gemini CLI, Gemini в Android Studio, бесплатный тариф Copilot. Нас интересует не то, «написал ли
ИИ код», а то, как вы ставите задачу, проверяете результат и исправляете ошибки.

**Время:** 1–2 часа. **Срок сдачи:** 3 дня.

## Старт

Создайте свой репозиторий из шаблона https://github.com/karasvladimir/fx-rates-starter
кнопкой **Use this template** (не форком) и работайте в нём. Репозиторий может быть публичным
или приватным — если приватный, дайте доступ пользователю `karasvladimir`.

Это приложение на Kotlin Multiplatform + Compose Multiplatform (Decompose, MVIKotlin,
kotlin-inject, Ktor) со списком курсов валют. Данные берутся из API Frankfurter, ключ не нужен.
Нужны JDK 21, Android SDK 37 и актуальная Android Studio (AGP 9.5).

Правила проекта лежат в `AGENTS.md` и `docs/`. Они обязательны: мы оцениваем, насколько итоговый
код им соответствует.

## Задача: экран валюты

По нажатию на валюту в списке открывается экран, на котором есть:

- текущий курс к базовой валюте;
- курсы за последние 30 дней (можно списком, график по желанию);
- изменение за период в абсолютном значении и в процентах, со знаком;
- состояния загрузки и ошибки с кнопкой повтора;
- возврат назад к списку.

Логику экрана покройте unit-тестами.

## Что сдать

Пришлите ссылку на репозиторий. В нём должны быть:

1. **Решение с историей коммитов** — без squash и без force-push.
2. **Полные логи всех ИИ-сессий без правок** в папке `ai-logs/`:
    - Claude Code — `.jsonl` из `~/.claude/projects/…` или `/export`;
    - Codex — `~/.codex/sessions`;
    - Cursor — экспорт чатов;
    - для других инструментов — любой полный экспорт.

   Секретов в логах быть не должно. Если логи слишком большие для git, приложите их архивом к
   письму.
3. **`SOLUTION.md`** в корне репозитория, до полстраницы:
    - какие инструменты и модели вы использовали;
    - как передали агенту контекст проекта;
    - где ИИ ошибся и как вы это заметили;
    - что исправили руками.

На следующем этапе вы покажете решение и внесёте в него небольшое изменение при нас.
